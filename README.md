A GitHub-compatible git forge in a single Node process, built from scratch: an in-process git object model and pack protocol (smart HTTP upload-pack/receive-pack), the REST v3 surface, a GraphQL v4 endpoint with its own parser and executor, and an MCP endpoint — all standard library only, all state deterministic so live runs and replays agree byte for byte.

## Run it

```sh
node --experimental-strip-types main.ts
```
